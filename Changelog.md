# Change history

* **Version 1.1.2.0 (2026-08-14)** : Removed support for Net9.0, added support for Net10.0, updated the NuGet packages, fixed the deletion of the wrong entry for the entries with a star, fixed the ICS file handling, fixed the arguments of the ArgumentException in the logger configuration, fixed the locale variables of the Docker images, added a test project. Warning: The Docker images of the versions 1.1.0 and 1.1.1 and the file Published/1.1.1/win-x64.zip contained a development configuration with real credentials, do not use these artifacts.
* **Version 1.1.1.0 (2025-01-05)** : Updated Nuget packages, added audit mode, moved to Net9.0.
* **Version 1.1.0.0 (2024-02-24)** : Added Docker support, made logging to Telegram optionally, updated NuGet packages.
* **Version 1.0.0.0 (2023-11-11)** : 1.0 release.
